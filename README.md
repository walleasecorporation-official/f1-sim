# F1 Racing Simulator — 영암 코리아 인터내셔널 서킷 · 2026 규정

Three.js(r160)로 만든 브라우저 F1 레이싱 시뮬레이터입니다. 빌드 과정 없이 `index.html` 하나로 실행되며, PC(키보드)와 휴대폰(기울기 조향) 모두에서 플레이할 수 있습니다.

- **트랙:** 영암 코리아 인터내셔널 서킷 (5.6 km, 18개 코너), 연석·자갈 트랩·방호벽·호수·관중석
- **차량:** 2026 F1 규정 제원 (768 kg, 휠베이스 3.4 m, 액티브 에어로, ICE ≈400 kW + MGU-K 350 kW)
- **물리:** 다운포스 기반 코너링, 타이어 마찰원, 슬립 각 자전거 모델, ERS·오버테이크 모드, 타이어 온도·마모, 락업, 슬립스트림, 연료 소모, 그라운드 이펙트·포퍼싱 → [F1 물리 적용 내역](docs/PHYSICS_PROPOSAL.md)
- **레이스:** AI 상대 차량 0~7대, F1식 스타트 신호, 순위·간격·결과표
- **설정:** 랩 수, 타이어 컴파운드, 주행 보조 프리셋, 액티브 에어로 자동/수동, 그래픽 품질

## 어디서 어떻게 플레이하나요?

| 방법 | 대상 | 휴대폰 기울기 조향 | 준비 |
|------|------|:---:|------|
| **A. 바로 해보기** | PC · 휴대폰 | 페이지 환경에 따라 다름 (안 되면 버튼 조향) | 없음 — 링크만 열기 |
| **B. GitHub Pages** | PC · 휴대폰 | ✅ (HTTPS) | 저장소 설정 2곳 변경 |
| **C. Netlify Drop 등 무료 호스팅** | PC · 휴대폰 | ✅ (HTTPS) | ZIP 받아서 드래그 |
| **D. PC에서 바로** | PC | — | ZIP 받아서 더블클릭 |
| **E. 같은 와이파이 휴대폰** | 휴대폰 | ❌ (HTTP라 버튼 조향) | PC에서 로컬 서버 실행 |

> 휴대폰 **기울기 조향은 HTTPS 주소(또는 localhost)에서만** 동작합니다. 브라우저가 일반 HTTP 페이지에서는 기울기 센서를 막기 때문입니다. 센서를 쓸 수 없으면 게임이 자동으로 화면의 **◀ ▶ 조향 버튼**으로 전환하므로, 어느 방법이든 플레이는 가능합니다.

### A) 바로 해보기 (가장 쉬움)

<!-- ARTIFACT_LINK -->

1. 위 링크를 엽니다. 설치나 로그인은 필요 없습니다.
2. **PC:** 시작 화면에서 랩 수·타이어 등을 고르고 **RACE START** → `W` `A` `S` `D`로 주행합니다.
3. **휴대폰:** 같은 링크를 휴대폰 브라우저(Chrome / Safari)에서 열고 → 가로로 돌린 뒤 → **RACE START**를 누릅니다.
   - iPhone은 이때 "동작 및 방향 접근" 권한을 묻습니다. **허용**을 누르면 폰을 핸들처럼 기울여 조향합니다.
   - 이 링크는 다른 페이지 안에 게임을 띄우는 방식이라 브라우저가 기울기 센서를 막을 수 있습니다. 그러면 "기울기 센서를 쓸 수 없어 버튼 조향으로 전환했어요"라는 안내가 뜨고, 왼손 **◀ ▶** 버튼과 오른손 **BRAKE / THROTTLE** 버튼으로 바뀝니다.
   - 기울기 조향을 확실히 쓰려면 아래 **B** 또는 **C** 방법을 권장합니다.

### B) GitHub Pages (휴대폰 기울기 조향 권장)

저장소에 이미 배포 워크플로(`.github/workflows/pages.yml`)가 들어 있습니다. 저장소 설정만 바꾸면 push할 때마다 자동으로 배포됩니다.

1. **저장소 공개 여부 정하기**
   - 이 저장소는 현재 **비공개(private)** 입니다. GitHub Pages를 비공개 저장소에서 쓰려면 **유료 플랜**(개인 계정 Pro, 조직 Team / Enterprise)이 필요합니다.
   - **무료 플랜이라면 공개로 전환:** 저장소 **Settings → General →** 맨 아래 **Danger Zone → Change visibility → Change to public** → 저장소 이름을 입력해 확인합니다.
   - **비공개를 유지하려면:** 유료 플랜을 쓰거나, 아래 **C** 방법을 쓰세요.
2. **Pages 소스 설정:** 저장소 **Settings → Pages → Build and deployment → Source**를 **"GitHub Actions"** 로 바꿉니다. (저장은 따로 필요 없습니다.)
3. **배포 실행** — 둘 중 하나:
   - 기본 브랜치 `claude/f1-simulator-improvements-nml6oi`(또는 나중에 병합할 `main`)에 push 합니다.
   - 또는 **Actions** 탭 → 왼쪽 목록의 **"Deploy to GitHub Pages"** → **Run workflow** → 브랜치 선택 → **Run workflow**.
4. 1~2분 뒤 Actions 실행이 초록색 ✓가 되면 아래 주소로 접속합니다. (실제 주소는 Settings → Pages 맨 위에도 표시됩니다.)

   **https://walleasecorporation-official.github.io/f1-sim/**

5. **휴대폰에서 열기:** 휴대폰 브라우저에 위 주소를 입력합니다. HTTPS 주소이므로 기울기 조향이 동작합니다.
   - 폰을 가로로 돌리고 **RACE START** → iPhone은 동작 권한 팝업에서 **허용**을 누릅니다. (Android Chrome은 권한 팝업 없이 바로 동작합니다.)
   - 실수로 거부했다면 탭을 닫고 페이지를 다시 연 뒤 RACE START를 누르면 다시 묻습니다.
   - 공유 메뉴의 **홈 화면에 추가**를 쓰면 주소창 없이 전체 화면으로 실행됩니다.

> 배포가 `Branch "…" is not allowed to deploy to github-pages due to environment protection rules` 오류로 실패하면: **Settings → Environments → github-pages → Deployment branches and tags**에 해당 브랜치(`main` 등)를 추가하세요. 처음에는 기본 브랜치만 배포가 허용됩니다.

### C) 비공개로 유지하면서 무료 HTTPS 호스팅

저장소는 비공개로 두고, 게임 파일만 무료 정적 호스팅에 올리는 방법입니다.

1. GitHub 저장소 페이지에서 초록색 **Code → Download ZIP**을 눌러 내려받습니다.
2. 압축을 풉니다. `index.html`, `css/`, `js/`가 들어 있는 폴더가 업로드할 폴더입니다.
3. **https://app.netlify.com/drop** 을 열고 그 폴더를 통째로 브라우저 창에 끌어다 놓습니다.
   - 몇 초 뒤 `https://<임의 이름>.netlify.app` 주소가 생깁니다.
   - 로그인 없이 올린 사이트는 임시로만 유지됩니다. 계속 쓰려면 무료 가입 후 사이트를 저장(claim)하세요.
   - 다른 선택지: **Cloudflare Pages**(Workers & Pages → Create → Pages → Upload assets에서 폴더 업로드), **Vercel**(폴더에서 `npx vercel` 실행).
4. 받은 **https 주소를 휴대폰에서 엽니다** → 가로로 돌리고 RACE START → (iPhone) 동작 권한 허용.

> 이렇게 올린 사이트는 주소를 아는 사람이면 누구나 열 수 있습니다. 비공개로 유지되는 것은 GitHub의 코드 저장소입니다.

### D) PC에서 바로

1. **Code → Download ZIP**으로 내려받아 압축을 풀거나, 저장소 접근 권한이 있다면 clone 합니다.
   ```bash
   git clone https://github.com/walleasecorporation-official/f1-sim.git
   ```
2. **`index.html`을 더블클릭**하면 브라우저에서 바로 실행됩니다. three.js가 `js/vendor`에 들어 있고 텍스처도 코드로 생성하므로 **인터넷 없이도** 동작합니다.
3. 또는 로컬 서버로 실행합니다.
   ```bash
   cd f1-sim
   python3 -m http.server 8080
   # 또는
   npx http-server -p 8080 -c-1 .
   ```
   그다음 브라우저에서 **http://localhost:8080** 을 엽니다.

### E) 같은 와이파이의 휴대폰으로 PC 서버 접속

1. D-3처럼 PC에서 로컬 서버를 실행합니다. (`python3 -m http.server 8080`과 `npx http-server`는 기본으로 같은 네트워크의 다른 기기 접속을 받습니다.)
2. PC의 IP 주소를 확인합니다.
   - Windows: `ipconfig` → "IPv4 주소"
   - macOS: `ipconfig getifaddr en0`
   - Linux: `hostname -I`
3. 같은 와이파이에 연결된 휴대폰에서 **`http://<PC IP>:8080`** (예: `http://192.168.0.12:8080`)을 엽니다. 열리지 않으면 PC 방화벽에서 8080 포트(또는 Python/Node)를 허용하세요.
4. 이 주소는 HTTPS가 아닌 **일반 HTTP**라서 브라우저가 기울기 센서를 막습니다. 게임은 자동으로 **◀ ▶ 버튼 조향**으로 전환됩니다. **기울기 조향을 쓰려면 B 또는 C 방법**을 쓰세요.

## 조작법

| 동작 | PC | 모바일 |
|------|----|--------|
| 가속 | `W` / `↑` | 오른쪽 **THROTTLE** 페달 |
| 브레이크 (멈춘 뒤 계속 누르면 후진) | `S` / `↓` | 왼쪽 **BRAKE** 페달 |
| 조향 | `A` `D` / `←` `→` | 폰을 **핸들처럼 기울이기** (센서를 못 쓰면 ◀ ▶ 버튼) |
| 부스트 (오버테이크 모드) | `Shift` (또는 `Space`) 누르는 동안 | **BOOST** 버튼 누르는 동안 |
| X-MODE 켜기/끄기 (액티브 에어로 **수동**일 때) | `E` | **X-MODE** 버튼 (수동일 때만 표시) |
| 카메라 전환 (CHASE / ONBOARD / T-CAM) | `V` (또는 `C`) | **CAM** |
| 가장 가까운 트랙 중앙으로 복귀 | `R` | **↺** |
| 일시정지 | `P` / `Esc` | **❚❚** |
| 현재 자세를 기울기 영점으로 | — | **◎** |

- **부스트(오버테이크 모드):** 각 직선의 X-MODE 구간 시작점이 판정 지점입니다. 이곳을 지날 때 **앞차와 1초 이내**이면 `OVERTAKE` 배지가 켜지고(BOOST 버튼도 보라색으로 빛남) 다음 판정 지점까지 부스트를 쓸 수 있습니다. 부스트 중에는 MGU-K가 337 km/h까지 350 kW를 유지하고, 그 랩의 에너지 회수 한도가 0.5 MJ 늘어납니다. 가속 페달을 밟은 상태에서 배터리가 남아 있어야 동작합니다.
- **X-MODE:** 직선 구간에서 앞뒤 윙 플랩을 눕혀 항력과 다운포스를 줄입니다. 기본(자동)에서는 직선 구간에 들어가면 저절로 켜지고, 브레이크를 밟거나 핸들을 꺾거나 구간을 벗어나면 Z-MODE(코너 모드)로 돌아갑니다. 수동으로 설정하면 직선 구간에서 `X 가능` 표시가 뜰 때 `E` / X-MODE 버튼으로 직접 켭니다.
- **모바일 버튼 배치:** 기울기 조향일 때 왼손 = BRAKE + BOOST / X-MODE, 오른손 = THROTTLE. 버튼 조향일 때 왼손 = ◀ ▶, 오른손 = BRAKE + THROTTLE. 시작 화면의 **조향 감도**(낮음 / 보통 / 높음)로 최대 조향에 필요한 기울기 각도를 바꿀 수 있습니다.

### HUD 읽는 법
- **왼쪽 위:** 순위(P1/전체)와 앞차와의 간격(1위면 `LEAD`, 1초 이내면 강조), 랩, 현재/LAST/BEST 랩타임 · 타이어 4개(색 = 온도: 차가움/적정/과열, 숫자 = 마모 %)와 남은 연료(kg)
- **아래 가운데:** RPM 표시등, 속도, 기어, **ERS** 배터리 막대(`DEPLOY` 사용 중 / `HARVEST` 회수 중), `OVERTAKE` 배지, `Z-MODE` / `X 가능` / `X-MODE` 배지
- **경고등:** `TC` `ABS` `ESP`(보조 장치 작동 — 회색이면 그 보조가 꺼진 설정), `LOCK-UP`, `WHEELSPIN`, `SLIPSTREAM`(앞차 뒤에서 항력 감소), `DIRTY AIR`(앞차 후류로 다운포스 감소)
- **오른쪽 위:** 미니맵(플레이어 = 빨간 화살표, 상대 = 팀 색 점), 카메라 모드, 현재 노면(DRY ASPHALT / KERB / GRASS / GRAVEL), 다가오는 코너 이름

## 레이스 설정 (시작 화면)

선택한 값은 브라우저에 저장되어 다음 접속 때도 유지되고, 메뉴에서 바꾸면 그리드에 바로 반영됩니다.

| 설정 | 선택지 | 설명 |
|------|--------|------|
| 랩 수 | 3 / 5 / 10 | 랩 수에 맞춰 시작 연료가 정해집니다. 길수록 타이어 마모 차이가 커집니다. |
| 타이어 | SOFT / MEDIUM / HARD | 소프트: 그립↑, 마모·과열 빠름 · 미디엄: 균형 · 하드: 그립↓, 오래 감, 예열 느림 |
| 주행 보조 | 초보 / 보통 / 프로 | 초보: TC + ABS + 스핀 방지(ESP) · 보통: TC + ABS · 프로: 보조 없음 (실제 F1과 동일). 기본값은 모바일 초보, PC 보통 |
| 상대 차량 | 0 ~ 7대 | AI 상대 차량 수 (기본 모바일 4대, PC 5대). 플레이어는 그리드 **맨 뒤**에서 출발합니다. |
| 액티브 에어로 | 자동 / 수동 | 자동: 직선 구간에서 X-MODE 자동 전환 · 수동: `E` 키 / X-MODE 버튼으로 직접 |
| 그래픽 | 낮음 / 중간 / 높음 | 바꾸면 페이지가 `?quality=` 옵션으로 다시 열립니다. 기본: PC 높음, 모바일 중간 |
| 조향 감도 (모바일) | 낮음 / 보통 / 높음 | 최대 조향에 필요한 기울기 38° / 28° / 20° |

## 적용된 F1 물리 요약

모든 항목의 구현 방법과 상수, 게임성을 위한 타협은 **[docs/PHYSICS_PROPOSAL.md — F1 물리 적용 내역](docs/PHYSICS_PROPOSAL.md)** 에 정리했습니다.

- **2026 제원:** 최저 중량 768 kg + 연료, 휠베이스 3.4 m, 전폭 1.9 m, 18″ 타이어, 무게 배분 약 45 : 55
- **다운포스 코너링 + 마찰원:** 타이어 한계 = μ · (무게 + ½ρ·ClA·v²), 제동·가속 중에는 횡그립이 줄어 트레일 브레이킹이 유리
- **슬립 각 자전거 모델:** 간이 Pacejka 타이어로 언더스티어·오버스티어·스핀 표현, TC / ABS / ESP 보조는 난이도 프리셋
- **액티브 에어로:** 직선 구간 X-MODE(항력·다운포스↓) ↔ 코너 Z-MODE, 윙 플랩 애니메이션
- **파워유닛 · ERS:** ICE ≈400 kW + MGU-K 350 kW, 배터리 4 MJ, 랩당 회수 8.5 MJ, 290 km/h부터 MGU-K 출력 감소, 오버테이크 모드
- **하중 이동:** 제동 시 앞 하중↑(앞뒤 그립 배분), 피치·롤, 코너 바깥 타이어 발열↑
- **노면:** 아스팔트 / 연석 / 잔디 / 자갈 트랩마다 그립과 저항이 다름
- **타이어 온도·마모:** 컴파운드별 적정 온도 창, 마모 절벽, 과열 시 마모 가속, 락업 시 플랫 스팟
- **슬립스트림 / 더티 에어:** 앞차 뒤 80 m 이내 항력 감소, 45 m 이내 다운포스 감소 (AI 상대 차량에도 동일 적용)
- **연료:** ICE가 한 일만큼 연료를 태워 차가 점점 가벼워짐
- **그라운드 이펙트 · 포퍼싱:** 차고에 따라 다운포스가 변하고, 너무 낮으면 플로어가 실속해 차체가 튐

## URL 옵션

주소 뒤에 붙여 씁니다. 예: `https://walleasecorporation-official.github.io/f1-sim/?quality=low&fps`

| 옵션 | 설명 |
|------|------|
| `?quality=low\|medium\|high` | 그래픽 품질 강제 (기본: PC `high`, 모바일 `medium`) |
| `?mobile=1` / `?mobile=0` | 모바일 UI 강제 켜기/끄기 (PC에서 모바일 화면 확인용 등) |
| `?fps` | FPS와 현재 렌더 해상도 배율 표시 |

## 모바일 최적화
- 정적 차체를 재질별로 병합하고 나무를 InstancedMesh로 그려 draw call을 줄였습니다.
- AI 상대 차량은 플레이어 차량을 재질별로 병합한 저사양 모델(차량당 draw call 약 10개)이고, 물리 대신 미리 계산한 레이싱 라인과 속도 프로파일 위를 달려 CPU 부담이 작습니다.
- FPS에 따라 렌더 해상도를 자동으로 조절합니다(적응형 pixel ratio).
- 모든 텍스처는 Canvas로 생성해 다운로드할 이미지가 없습니다.
- 그림자맵은 `high`에서만 켜고, 다른 품질에서는 차량 아래 블롭 섀도를 씁니다.
- 주행 중 위치 판정은 직전 위치 주변만 검사하고, HUD DOM은 값이 바뀔 때만 갱신하며 미니맵은 초당 10번만 다시 그립니다.
- 화면이 꺼지지 않게 Wake Lock을 쓰고, 탭이 백그라운드로 가면 자동으로 일시정지합니다.

## 문제 해결
- **기울기 조향이 안 돼요:** 주소가 `https://`인지 확인하세요(방법 B·C). iPhone에서 권한을 거부했다면 탭을 닫고 다시 연 뒤 RACE START를 누르세요. 그래도 안 되면 버튼 조향으로 플레이할 수 있습니다.
- **조향이 한쪽으로 쏠려요:** 편한 자세로 폰을 잡고 **◎** 버튼을 눌러 영점을 다시 잡으세요.
- **화면이 끊겨요:** 시작 화면에서 그래픽을 **낮음**으로 바꾸거나 주소에 `?quality=low`를 붙이세요. 상대 차량 수를 줄여도 가벼워집니다.
- **차가 자꾸 돌아요:** 주행 보조를 **초보**(스핀 방지 포함)로 두고, 코너에서는 브레이크를 먼저 밟고 핸들을 꺾으세요.
